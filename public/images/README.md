# Галерия снимки

## Филтри в сайта

| Категория | Бутон | Име на файл |
|-----------|-------|-------------|
| `yard` | **Двор** | `yard-01.jpg`, `yard-02.jpg`, … |
| `inside` | **Вътре в хотела** | `inside-01.jpg`, `inside-02.jpg`, … |
| `food` | **Храна** | `food-01.jpg`, `food-02.jpg`, … |

## Текущо състояние

- **Двор:** `yard-01.jpg` … `yard-07.jpg` (7 снимки)
- **Вътре:** `inside-01.jpg` … `inside-17.jpg` (17 снимки)
- **Храна:** `food-01.jpg` … `food-05.jpg` (5 снимки)

## Нова снимка

1. Качете в `public/images/` със следващия номер (напр. `yard-06.jpg`)
2. Добавете ред в `src/data/galleryData.ts`

## Други файлове

- `hero.png` — начална страница
- `logo.png` — лого
